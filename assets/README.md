# assets 폴더

사진과 미리보기 이미지를 여기에 넣습니다. 넣은 뒤 `config.js` 의 경로를 바꾸세요.

| 파일 | 쓰임 | 권장 사양 |
| --- | --- | --- |
| `og.jpg` | 카카오톡 미리보기 (필수) | 1200×630 JPG, 300KB 이하 |
| `cover.webp` | 커버 한 장 | 세로 4:5 또는 3:4, 가로 1200px, 300KB 이하 |
| `01.webp` ~ | 갤러리 | 가로 1200px, 장당 200KB 안팎 |
| `bgm.mp3` | 배경음악 (선택) | 2MB 이하 |

현재 들어 있는 `og.jpg` 는 글자만 있는 임시 이미지입니다. 실제 사진으로 바꾸세요.

WebP 변환은 <https://squoosh.app> 에서 사진을 끌어다 놓고 오른쪽에서 WebP 를 고르면 됩니다.
